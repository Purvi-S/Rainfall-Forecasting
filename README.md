# 🌧️ Rainfall Forecasting

Predict whether it will **rain tomorrow** from daily weather observations,
using and comparing three classifiers — **Random Forest**, **SVM (RBF)** and
**XGBoost** — over 50,000+ records. The pipeline handles missing data,
categorical encoding and class imbalance, selects the best model by ROC-AUC,
and produces a full evaluation report (confusion matrix, ROC curve, feature
importances).

## 📁 Dataset

This project supports two data sources, both with identical columns so the
pipeline runs unchanged on either:

**1. Real-world data — Kaggle "Rain in Australia" (`weatherAUS.csv`)**
- ~145,000 daily weather observations from ~49 Australian weather stations
  (2007–2017), with a `RainTomorrow` (Yes/No) target.
- Original source: **Australian Government — Bureau of Meteorology**
  (© Commonwealth of Australia), redistributed on Kaggle.
- Kaggle page: search *"Rain in Australia"* on kaggle.com — dataset slug
  `jsphyg/weather-dataset-rattle-package`.
  *(Please verify the link on Kaggle directly, as dataset URLs can change.)*
- To use it: download `weatherAUS.csv`, save it as `data/weather.csv`, then run
  `python -m src.train`. No code changes needed.

**2. Bundled synthetic data (default, no download required)**
- Generated by `src/generate_synthetic_data.py` — 50,000 daily records with
  realistic, correlated weather features (humidity, pressure, cloud cover,
  rainfall, temperature, wind) and a ~22% rain-tomorrow rate that mirrors the
  real dataset's class imbalance.
- Used automatically if `data/weather.csv` is absent, so the project always
  runs out of the box. **The metrics reported above are from this synthetic
  dataset** — real-world figures will differ.

## 🚀 Quickstart

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate the synthetic dataset (skip if using the real data below)
python -m src.generate_synthetic_data --rows 50000 --out data/weather.csv

# 3. Train and compare all three models
python -m src.train

# 4. Evaluate the best model and write plots to reports/
python -m src.evaluate
```

After step 3 you'll find the metrics in `reports/metrics.json` and the saved
model in `models/best_model.joblib`. Step 4 writes `confusion_matrix.png`,
`roc_curve.png` and `feature_importance.png` to `reports/`.

## 🔧 How it works

- **Preprocessing** — median imputation for numeric columns, most-frequent
  imputation + one-hot encoding for categoricals, and standard scaling for the
  SVM (tree models skip scaling). All wrapped in a scikit-learn
  `Pipeline` + `ColumnTransformer` so there's no train/test leakage.
- **Class imbalance** — rainy days are ~22% of the data, so the models use
  `class_weight="balanced"` and are compared on ROC-AUC and F1, not accuracy
  alone.
- **Model selection** — all three models train on identical splits; the one
  with the highest ROC-AUC is saved.
